# KjTabBar

[英語版 README](./README.md)

Windows エクスプローラー（`explorer.exe`）を独自のタブバーで統合し、タブ型ファイラーのように操作できるようにする常駐型デスクトップアプリケーションです。
エクスプローラー本体を直接フック・改造するのではなく、独立したツールウィンドウをエクスプローラーの上部に追従・密着させることで、安定した動作と高い互換性を実現しています。

![KjTabBar screenshot](./screenshot.png)

## 特徴

- **タブ化によるウィンドウ統合**
  - 複数のエクスプローラーをシステム全体で一元管理し、1つのタブバーウィンドウに統合します。
- **ドラッグ＆ドロップ対応**
  - タブの並び替え（左ボタンドラッグ）
  - タブをタブバーの外へドラッグし、エクスプローラー外でドロップすると、そのタブを別ウィンドウへ移し、元のタブを閉じる
  - タブへのファイル・フォルダ移動やコピー（外部からのドロップ）
  - タブバー非表示の独立したエクスプローラーウィンドウを、タブバー右端の専用「吸収」ゾーンへドラッグして離すと、新しいタブとして吸収・統合する
  - ドラッグによる吸収では、電源オプションなどのコントロールパネル配下項目も、同じ項目の既存タブがあっても別タブとして追加する
  - 右ドラッグドロップ時のコンテキストメニュー（「ここにコピー」「ここに移動」「シンボリックリンクをここに作成」など）
  - シンボリックリンク作成は現在のユーザー権限で試行し、権限不足時はWindowsのUAC確認後、専用の補助プロセスが失敗したリンクのみ管理者権限で再試行します。UACをキャンセルすると再試行を中止します。
- **シームレスな追従・UI連携**
  - エクスプローラーの位置・サイズ変更、DPI スケール変更にリアルタイムに追従
  - Windows のダークモード・ライトモード設定への自動追従
- **安定した常駐動作**
  - システムトレイ（タスクトレイ）に常駐し、バックグラウンドでリソースを適切に管理します。
  - プログラム自体の独立性が高いため、Windowsのアップデートなどによる影響を受けにくい設計です。

## 動作環境

- OS: Windows 10 / Windows 11
- ランタイム: .NET Framework 4.8.1

## デスクトップから開く場合のタブ選択

デスクトップ上のフォルダ、特殊項目、またはそれらへのショートカットを開いた場合のみ、取り込み先に同じ場所のタブがあれば選択して前面に表示し、なければ新しいタブを追加します。通常フォルダに加え、コントロールパネル本体・配下項目、PC、ネットワーク、ごみ箱などの特殊フォルダ全般を対象とします。

- 一致するタブが複数ある場合は、選択中の一致タブを優先し、それ以外は左端を選択します。既存の重複タブは残します。
- 特殊フォルダは表示名ではなく識別子や正規化したパスで照合し、コントロールパネル本体と各配下項目を区別します。
- タブの複製、ドラッグによる追加・ウィンドウ吸収、＋ボタンは、同じ場所でも新しいタブを作成します。デスクトップからのドラッグも再利用の対象外です。
- デスクトップ以外からの起動や、タブ操作に伴う内部ウィンドウ生成には適用しません。

この動作はソースコードに反映済みです。実際のデスクトップ操作による起動元判定と表示・ウィンドウ切替は、実機での確認が必要です。

## 使い方

1. アプリケーション（`KjTabBar.exe`）を起動すると、タスクトレイに常駐します。
2. Windows エクスプローラーを開くと、ウィンドウ上部にタブバーが自動的に表示されます。
3. デスクトップ上のフォルダ・特殊項目や、それらへのショートカットを開くと、同じ場所の既存タブを選択します。一致するタブがなければ、新しいタブとして追加します。
4. **タブの操作**:
   - 右にある `＋` ボタンでフォルダ選択ダイアログを開き、新しいタブを追加できます（特殊フォルダの選択にも対応）。
   - タブ先頭にはパスごとのアイコンを表示し、特殊フォルダやコントロールパネル配下項目はシェル固有アイコンを表示します。
   - タブを右クリックすると、`タブの複製` `別ウィンドウで開く` `パスのコピー` `タブを閉じる` などの操作が可能です。
   - タブをタブバーの外へドラッグし、エクスプローラー外でドロップすると、そのタブを独立した別ウィンドウとして開き直し、元のタブは閉じられます。
   - タブバーの表示されていない独立したエクスプローラーウィンドウを吸収する場合は、タブバー右端の専用 `吸収` ゾーンへドラッグして、その場所で離してください。
5. **設定**:
   - タブバーの背景部分（空いている場所）を右クリックして `設定...` を選択すると、タブのフォントサイズなどを変更できます。
6. 終了する場合は、タスクトレイのアイコンを右クリックして `終了` を選択してください。

## インストール・アンインストールについて

- インストール時にセットアップカスタムアクションでスタートアップに登録します（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）。
- アンインストール時は、専用のアンインストーラーにより一致する自動起動レジストリのみをクリーンアップします。設定ファイル（`settings.xml`）や DPAPI で保護されたタブ履歴ファイル（`tabs.txt`）は、ユーザーデータとして `%APPDATA%\KjTabBar` 配下に保持されます。

## タブリストのエクスポート・インポート（v1.4.6.0）

タブまたはタブバーの空白部分を右クリックして実行する。対象はそのウィンドウのタブリスト。
UTF-8テキスト（`.txt`、出力はBOMなし・CRLF、入力はBOMあり／なしとCRLF／LFに対応）を使用する。

```text
active=1
C:\Users
D:\Documents
shell:RecycleBinFolder
```

- 先頭行は `active=` と0始まりの選択位置（例では2番目の `D:\Documents`）。以降は1行1パス。
- インポートは現在のリストを置き換える。順序、重複、日本語、UNCパス、Shellパスを保持する。
- フォルダの存在・アクセス可否を検査しない。選択タブへの移動は試みるが、開けないパスもリストに残す。
- 空リスト、空白行、不正な選択位置、UTF-8以外などの形式エラーは読み込み前に拒否し、現在のリストを変更しない。
- ファイル自体の読み書きに失敗した場合はエラーを表示する。タブ操作の実行中はメニューを無効化する。
